# school_data
Automated School Data Collection Assignment using Python and OpenPyXL. The project collects, validates, and organizes school information into a structured Excel format while maintaining template consistency. Includes data validation, missing data reporting, and documentation for execution and setup.

## Objective
Collect and validate school information for provided locations.

## Technologies Used
- Python
- Pandas
- OpenPyXL

## Files
- final_dataset.xlsx
- missing_data_report.xlsx

## Execution

pip install -r requirements.txt

python src/main.py
